## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎙️ **Real-Time Transcription** | Captures microphone audio and transcribes it live using Whisper (via `@xenova/transformers`, runs locally) |
| 🖥️ **Screen OCR** | Reads text from your screen every 5 seconds using `tesseract.js` — no screen recording bots |
| 🤖 **AI Coaching** | Combines transcript + screen text + your knowledge base → sends to local LLM for instant, actionable suggestions |
| 👁️ **Stealth Overlay** | Floating, always-on-top widget that is **completely invisible to screen-sharing tools** (Zoom, Teams, Meet, etc.) |
| 📚 **Knowledge Base (RAG)** | Upload PDF, DOCX, TXT, or Markdown files — indexed locally with vector embeddings, automatically included in AI context |
| 📝 **Post-Meeting Tools** | One-click meeting summary, action items, follow-up email draft — all generated by your local LLM |
| 🎭 **Role Templates** | Sales coach, interview coach, negotiation coach, debate coach, presentation coach — or write your own system prompt |
| 🔒 **Total Privacy** | Everything runs locally. No telemetry, no analytics, no data ever leaves your machine |
| ⚡ **Free Forever** | No paid tiers, no API keys required. Just install Ollama and pick a model |

## 🚀 Quick Start

### Prerequisites

- **Node.js** 18+ ([download](https://nodejs.org))
- **Ollama** (the local LLM runtime — see below)

### 1. Install Ollama

Ollama runs LLMs locally on your machine. Install it from [ollama.com](https://ollama.com):

**macOS:**
```bash
brew install ollama
# or download from https://ollama.com/download/mac
```

**Windows:**
Download the installer from [ollama.com/download/windows](https://ollama.com/download/windows)

**Linux:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### 2. Pull a Model

Birdly works with **any Ollama model**. Here are our recommendations:

| Model | Size | Best For | Command |
|-------|------|----------|---------|
| `llama3.2` | 2 GB | Best balance of speed & quality | `ollama pull llama3.2` |
| `phi3:mini` | 2.3 GB | Fastest responses, great for real-time | `ollama pull phi3:mini` |
| `gemma2:2b` | 1.6 GB | Ultra fast, decent quality | `ollama pull gemma2:2b` |
| `qwen2.5:3b` | 1.9 GB | Excellent multi-language support | `ollama pull qwen2.5:3b` |
| `llama3.1:8b` | 4.7 GB | Higher quality, needs good GPU | `ollama pull llama3.1:8b` |
| `mistral` | 4.1 GB | Great for instruction following | `ollama pull mistral` |

**Start Ollama server** (usually starts automatically, but you can also run):
```bash
ollama serve
```

### 3. Clone & Install Birdly

```bash
git clone https://github.com/belugazeroday/birdly.git
cd birdly
npm install
```

### 4. Run in Development Mode

```bash
npm run dev
```

This starts:
- Vite dev server for the main renderer (port 5173)
- Vite dev server for the overlay (port 5174)
- Electron main process with hot reload

### 5. Build for Production

```bash
npm run build      # Build all bundles
npm run dist       # Package for your platform
```

Platform-specific:
```bash
npm run dist:mac   # .dmg + .zip
npm run dist:win   # .exe (NSIS installer)
npm run dist:linux # .AppImage + .deb
```

## 🎮 Usage

### Starting a Session

1. **Open Birdly** — the main dashboard appears
2. Click **"Start Session"** to begin
3. Birdly will:
   - Request microphone permission (for audio capture)
   - Start OCR scanning your screen every 5 seconds
   - Auto-generate AI suggestions every 15 seconds
4. Click **✨ Get Suggestion** for an instant coaching tip

### Using the Stealth Overlay

Press **`Ctrl+Shift+B`** (or `Cmd+Shift+B` on Mac) to toggle the floating overlay widget.

The overlay:
- Is **completely invisible to Zoom, Teams, Google Meet, and any screen-sharing tool** (uses Electron's `setContentProtection(true)`)
- Floats above all other windows, on all virtual desktops
- Shows your latest AI suggestion in real-time, word by word
- Can be moved by dragging the header area

### Building Your Knowledge Base

1. Go to **Knowledge Base** tab
2. Drag & drop any **PDF, DOCX, TXT, or Markdown** files
3. Files are automatically:
   - Parsed and chunked locally
   - Embedded using `all-MiniLM-L6-v2` (auto-downloaded on first use)
   - Stored in a local vector database
4. During sessions, relevant chunks are automatically retrieved and included in AI prompts

### Post-Meeting Tools

After a session, go to **Post Meeting** tab:
- **Generate Summary** — creates a structured meeting summary with action items
- **Draft Email** — writes a professional follow-up email
- **Export Markdown** — saves everything as a `.md` file

## ⚙️ Configuration

All settings are in the **Settings** tab:

| Setting | Default | Description |
|---------|---------|-------------|
| Ollama URL | `http://localhost:11434` | Your Ollama server address |
| Model | `llama3.2` | Which model to use for suggestions |
| Temperature | `0.7` | Creativity level (0 = precise, 1 = creative) |
| Max Tokens | `512` | Max length of AI responses |
| Streaming | `on` | Show responses word-by-word |
| Role Template | General | Pre-built coaching personas |
| Overlay Opacity | `90%` | Transparency of the floating widget |
| Hotkey | `Ctrl+Shift+B` | Global keyboard shortcut |
| STT | `on` | Speech-to-text capture |
| OCR | `on` | Screen text capture |
| RAG | `on` | Knowledge base context |

### AI Stack

```
Microphone → MediaRecorder → @xenova/transformers (Whisper) → Transcript
Screen → desktopCapturer → tesseract.js (OCR) → Screen Text
Transcript + Screen Text + Knowledge Chunks → Ollama (local LLM) → Suggestion
Documents → pdf-parse/mammoth → text → @xenova/transformers embeddings → Vector Store
```

## 🔒 Privacy & Security

- **Zero telemetry** — no analytics, no crash reporting, nothing
- **Local LLM only** — Ollama runs entirely on your machine, no internet required
- **Local embeddings** — `all-MiniLM-L6-v2` runs in-process via ONNX Runtime
- **Local OCR** — `tesseract.js` runs in-process
- **Screen protection** — overlay uses `setContentProtection(true)`, making it invisible to all screen capture APIs
- **No accounts** — no login, no registration, no cloud sync
- **Open source** — every line of code is auditable
